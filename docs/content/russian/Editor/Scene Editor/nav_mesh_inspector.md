#### Инструменты 
Эти инструменты помогают генерировать и редактировать навигационную сетку:

#### Инструменты генерации

![](/img/inspectors/nav_mesh_inspector/generation_tools.PNG)

* Auto Generate: Как следует из названия, автоматически генерирует навигационную сетку с учётом параметров, указанных выше.
* Generate Grids: Генерирует сеточную навигационную сетку только для рельефа (terrain). Игнорирует сущности на сцене.
* Create New Face: Создаёт новую четырёхугольную грань навигационной сетки в координатах, где находится камера.
* Extrude: 
* Remove: Удаляет выбранное ребро навигационной сетки.
* Fill: Заполняет пространство между выбранными вершинами навигационной сетки, образуя грань.
* Grow Selection: Расширяет выделение, добавляя элементы, соседние с уже выбранными (работает для всех структур — вершин, рёбер и граней).
* Connect: Соединяет две выбранные вершины навигационной сетки, проводя между ними ребро.
* Subdivide: Делит ребро навигационной сетки, помещая вершину в его середину. Эта вершина соединяется с соседними вершинами и делит соответствующую грань.
* Weld: Удаляет вершины, образующие ребро, и превращает ребро в одну вершину. Соединяет старые соседние вершины с новой вершиной.
* Import Faces From Prefabs: Импортирует грани, которые были экспортированы для последующего использования.
* Import Body: <неизвестно>
* Make Quads When Possible: Выбирает соседние треугольные грани, которые могут образовать четырёхугольники (не формирующие вогнутый многоугольник). Это не создаёт самую оптимальную навигационную сетку с гранями максимальной площади, но локально выбирает треугольники, образующие грань наибольшей площади. Тем не менее, это значительно сокращает общее число граней.

#### Инструменты отладки

![](/img/inspectors/nav_mesh_inspector/debugging_tools.PNG)

* X-Z Keys: Размещает по две разные сферы на клавишу, и когда обе размещены, выдаёт статистику о пути, определённом между этими двумя сферами.
* Select Vertices Below Entities: Название говорит само за себя.
* Select Unwalkable Edges: <неизвестно>
* Fix Concave Faces: Превращает вогнутые грани в выпуклые.
* Select Unconnected Faces: <неизвестно>
* Calculate Auto Weld Points: <неизвестно>
* Select Inverted Faces: Находит и выбирает инвертированные грани, обращённые к рельефу (terrain).
* Find Path: <неизвестно>
* Paste Copied Faces: Название говорит само за себя.
* Copy Selected Faces: Название говорит само за себя.
* Export Faces as Prefab: Экспортирует выбранные грани для последующего использования.
* Ensure Faces Are Not Below Ground: Название говорит само за себя.
* Remove Unreachable Faces: Удаляет грани, не связанные ни с одним островом, на котором есть точка появления (spawn point). (Точки появления определяются согласно сущностям в Prefabs/editor_spawnpoints.xml, а также сущностям, содержащим скрипт AnimationPoint.)
* Find Tight Faces: Находит грани, площадь поверхности которых меньше заданного значения, и выбирает их. Можно нажать кнопку "Delete", чтобы удалить эти грани. После этого не забудьте выполнить "Remove Unused Vertices", о чём будет сказано несколько строк ниже.
* Remove Unused Vertices: Удаляет вершины, не связанные ни с одной гранью.
* Select Vertices At The Edges: Выбирает вершины, связанные только с 2 рёбрами, то есть не являющиеся частью непрерывного компонента грани.
* Select Vertices Without Edges: Просто выбирает грани, не связанные ни с одним ребром или гранью.
* Mark Elevation Problem Faces: Для отладочных целей выбираются грани, расстояние которых до нижней поверхности (меша или рельефа) превышает 1,2 метра.

#### Параметры автогенерации

![](/img/inspectors/nav_mesh_inspector/auto_generation_parameters.PNG)

Эти параметры определяют точность, охват и детали операции генерации навигационной сетки. Пояснение параметров приведено ниже:

* Build Detailed Nav Mesh: Если этот флажок установлен, используются следующие параметры, и строится детализированная навигационная сетка в соответствии с ними. Если флажок не установлен, следующие параметры не будут иметь значения.
* Cell Size: Определяет длину горизонтального ребра воксела выборки, исследуемого библиотекой Recast.
* Cell Height: Определяет длину вертикального ребра воксела выборки, исследуемого библиотекой Recast.
* Agent Max Slope: Максимальный угол, на который агент может подниматься (в градусах).
* Agent Height: Название говорит само за себя.
* Agent Max Climb: Максимальное количество метров, на которое агент может наступить (ступенька).
* Agent Radius: Название говорит само за себя.
* Edge Max Length: Максимально возможная длина ребра полигонов, генерируемых Recast.
* Edge Max Error: Максимальное расстояние, на которое граничные рёбра упрощённого контура могут отклоняться от исходного необработанного контура. (Определение из документации Recast.)
* Region Min Size: Минимальное количество ячеек [вокселей], допустимое для формирования изолированных островных областей. (Определение из документации Recast.)
* Region Merge Size: Любые регионы с количеством спанов меньше этого значения будут, по возможности, объединены с более крупными регионами. (Определение из документации Recast.)
* Detail Sample Distance: Задаёт расстояние выборки, используемое при генерации детализированного меша. (Только для детализации по высоте.) (Определение из документации Recast.)
* Detail Sample Max Error: Максимальное расстояние, на которое поверхность детализированного меша может отклоняться от данных карты высот. (Только для детализации по высоте.) (Определение из документации Recast.)


### Шаги автогенерации
* Сначала заполните пустые поля на вкладке параметров. Вы также можете придерживаться параметров по умолчанию.
* Нажмите кнопку "Auto Generate" (инструменты генерации) и дождитесь завершения операции.
* Нажмите кнопку "Make Quads When Possible" (инструменты генерации), чтобы превратить в четырёхугольники треугольники, образующие выпуклую форму.
* Нажмите кнопку "Find Tight Faces" (инструменты отладки), чтобы найти и выбрать узкие грани на границах.
* Нажмите клавишу "Delete" на клавиатуре, чтобы удалить выбранные грани.
* Если на границах всё ещё появляются узкие грани, повторяйте ту же процедуру, пока они не исчезнут.
* Нажмите кнопку "Remove Unused Vertices" (инструменты отладки), чтобы удалить вершины, больше не связанные ни с одной гранью.
* Вручную исправьте регионы, повреждённые из-за удалённых узких граней.
* Вы можете продолжить отладку и доработку с помощью упомянутых выше инструментов.
