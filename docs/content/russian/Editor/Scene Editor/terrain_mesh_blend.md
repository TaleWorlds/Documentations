Мы представляем новую систему смешивания меша с ландшафтом (Terrain Mesh Blend). Определённые слои ландшафта могут плавно сливаться с выбранными мешами. Высоту смешивания, плавность и случайные смещения высоты можно изменять. Эти значения можно сохранять в префабах, а также изменять на сцене для каждого меша отдельно. Смешивание по карте высот также можно использовать для изменения поведения смешивания относительно карты высот меша.

### Ограничения слоёв ландшафта

Слои ландшафта должны удовлетворять некоторым ограничениям, прежде чем они смогут стать слоем смешивания с мешем.

- Диффузная текстура должна иметь размер (2048, 2048) и формат DXT1 (без альфа-канала).
- Текстура нормалей должна иметь размер (2048, 2048) и формат BC5.
- Текстура бликов (specular) должна иметь размер (2048, 2048) и формат DXT1.
- У слоя не должны быть включены флаги «diffuse alpha» или «ground slope».

### Свойства материала

У меша должен быть материал с шейдером "terrain_mesh_blend_shader". Чтобы включить смешивание по карте высот, необходимо назначить текстуру карты высот и включить флаг шейдера "".

### Свойства меша

Свойства меша можно изменить в окнах Components/Mesh/Vector Arguments в инспекторе сущностей (Entity Inspector).

- Blend Height Threshold (порог высоты смешивания): максимальное расстояние для смешивания с ландшафтом
- Blend Smoothness (плавность смешивания): чем выше значение, тем более плавные переходы
- Random Amount (величина случайности): с помощью этого значения порог высоты смешивания может увеличиваться или уменьшаться в зависимости от положения пикселя
- Random Tile (случайное замощение): регулирует замощение (tile) случайной корректировки карты высот
- Heightmap Factor (фактор карты высот): управляет фактором карты высот меша. Чем больше значение, тем меньше смешивание в более высоких частях карты высот.
