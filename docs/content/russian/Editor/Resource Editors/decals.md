## Что такое декаль?

Декали — это способ проецирования материалов на другую геометрию. Они могут влиять на следующие каналы PBR-конвейера затенения: Albedo, Normal, Specular, Gloss и Occlusion. Таким образом, они изменяют конечный внешний вид других мешей и материалов. Их можно использовать для добавления разнообразия в сцену, например, грязи, слякоти, мха. Также это полезный инструмент для устранения повторяющихся текстурных тайлов на мешах. Их проекционная геометрия — кубы, и проекция выполняется в направлении оси Z.

## Как настроить материал декали?

Прежде всего, шейдер материала должен быть "Decal". Diffuse, NormalMap и SpecularMap можно установить на любую текстуру. Модель затенения будет такой же, как у "pbr_metallic".
![](/img/decal/top_properties.png)

#### Флаги шейдера материала

Флаги шейдера материала определяют, какие свойства затенения будут использоваться, и типы объектов, на которых декаль будет видна. Примечание: флаг "use_albedo" обязателен. Типичный пример материала декали, который будет виден на всех материалах, показан ниже.
![](/img/decal/material_shader_flags.png)

#### Обязательные настройки на вкладке 'Others'

Чтобы декаль отображалась корректно, флаги "Cull Front Faces" и "Don't Modify Depth Buffer" должны быть включены.
![](/img/decal/other_settings.png)

## Как настроить префаб декали?

Чтобы создать сущность/префаб декали, нужно добавить специальный меш (Decal Mesh) к пустой сущности. Затем материал этого меша нужно изменить на материал, подготовленный в первом разделе. Наконец, в разделе Components/Meta Mesh/Custom Mesh Parameters следует соответствующим образом задать значения UV Scale X/Y. Для обычной текстуры оба значения должны быть равны 1. Для текстуры типа атлас значения UV Scale и UV Offset должны быть установлены так, чтобы фокусироваться на нужной позиции текстуры внутри атласа.
